# analysis/

从 `experiments/` 与问题库重建的统计、图表与自检材料。**表达层**：不得手写数字，
每个数字都必须能由脚本重算、并指明来源（`experiments/<id>/` 或 `analysis/known-truth/`）。

| 路径 | 内容 |
| --- | --- |
| `known-truth/` | 已知真值问题库与评分器：自检流水线相对裸 agent 的差距（调研 §7 借鉴 #5） |

约定：

- 脚本零依赖（标准库），可在 CI / 子agent 环境直接跑，不因依赖漂移静默失效。
- 中间产物（图表、统计缓存）由脚本生成、不入库；入库的是脚本与结论——结论落成
  `experiments/` 的终态实验或 `paper/` 的引用。
- 引用 `analysis/` 数字的地方（含稿件）必须给出脚本路径与运行命令。
